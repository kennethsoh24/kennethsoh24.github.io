# Heart model

`heart.bin` is generated by these two scripts (Python 3, `numpy scipy scikit-image trimesh`):

    python3 heartmesh.py 0.02 heart_mid.obj   # builds the anatomical heart from signed-distance shapes
    python3 bake.py                           # bakes ambient occlusion + region weights, writes heart.bin

Anatomy is positioned in the painting's pixel coordinates (`U(px, py, z)`), so the painting
projects onto the model where each part was painted.
